# 转写风格指令诊断集

[English](README.md) · [技术报告 PDF](reports/main.pdf) · [中文报告](reports/REPORT_ZH.md) · [数据与原始输出](https://github.com/ickma2311/transcript-command-diagnostics/releases/tag/v0.1.0)

这个项目提供一套小型、可复现的英文指令诊断数据，检查句号和换行缺失、单个 `uh` 位置变化时，模型输出如何变化。评分区分“符合构造参考答案”“语法允许的替代解释”和“所有允许解释之外的错误”。

## 可以用来做什么

1. 换模型或修改提示词时，检查动作遗漏、禁止项错误和日期绑定问题。
2. 检查评分规则是否把输入歧义导致的合法替代解释也算成内容错误。
3. 从完整原始输出复算结果，研究失败案例或扩展新的诊断设计。

## 本次结果

测试集含240个A/R配对、480个条目、2880个文本版本。两个固定版本模型、两个提示前言，共11520条输出。A类输入移除边界后有两个合法状态，R类仍有唯一合法状态。

主提示下，不含语气词的R类正确数：Qwen保留边界240/240，移除边界239/240；Phi为225/240和216/240。前者只有1个不同配对且接近天花板，后者无法确认差异在预设±5个百分点内。

“移动uh让日期更倾向修饰后一个动作”的主假设未获得支持：两个模型主对照两臂的后向选择都为0/240。合并两个前言与三个语气词条件，2880条歧义输入中2701条合法输出全部选前一个动作。这个地板结果不能证明语气词没有影响。

一个评分例子：Qwen的一组240条歧义输入，119条符合原参考答案，235条符合定义的语法；其中116条是合法替代解释。语法合法仍不代表恢复了用户原意。

## 使用

按[英文 README 的 Quick start](README.md#quick-start-cpu-only)安装Python 3.12依赖、下载已校验的数据附件即可。复算和演示都只需要CPU，不下载模型权重。提供安全的数据生成包装器和自有输出评分命令。

## 结论适用范围

数据是程序生成的英文指令，只有一个时间短语结构和三类任务。本次没有实际ASR、语音、识别错字、人类标注或自我纠正。提示词明确要求忽略um/uh，且使用greedy、JSON schema约束生成。因此不能据此建议真实语音产品删除语气词，也不能声称测出了独立的标点或换行因果效应。
